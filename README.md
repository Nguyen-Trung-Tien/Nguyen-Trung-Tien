I enjoy taking part in the entire software development life cycle — from **understanding business requirements** and **designing system flows** to **implementing clean full-stack code** and **testing for quality and reliability**.

My learning and working mindset is driven by three principles:

## 🧠 Work Philosophy

```text
Business Requirements (BA) ➔ Domain & Data Flow ➔ Full-Stack System Design ➔ Development ➔ Quality Testing (QA) ➔ Deployment
```

### 📋 1. Requirements & Process (BA)
- Clarifying requirements with stakeholders and breaking them down into actionable user stories.
- Mapping operational workflows (such as inventory allocation or payment callbacks) to ensure logical consistency.

### 🏗️ 2. Clean Full-Stack Engineering
- Practicing modular architecture and clean code principles to keep projects maintainable.
- Utilizing AI coding tools (Cursor, Copilot, LLMs) for efficiency while maintaining full control over core architecture and business logic.

### 🧪 3. Quality & Testing (QA/Tester)
- Writing structured test cases and performing API testing (Postman) to catch bugs early.
- Verifying edge cases, data consistency, and transactional safety under concurrent scenarios.
