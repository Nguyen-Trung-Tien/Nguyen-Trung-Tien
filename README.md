### ⚡ Engineering Highlights

**Real-Time Pipeline Optimization**

Implemented a latest-frame processing strategy instead of processing every incoming frame.

```text
Camera
   ↓
Frame Stream
   ↓
Latest Frame Selection
   ↓
AI Pipeline
   ↓
Detection
   ↓
Event Processing
   ↓
TTS / Notification
```

This helps prevent queue congestion and keeps the system responsive under continuous video input.

**Edge AI / Offline Fallback**

Designed fallback processing using on-device AI technologies so core functionality can continue when network connectivity becomes unavailable.
